# 05 分发计划

> 定位已变更（2026-08-11）：免费情怀作品，不做任何商业化。首发方式是**打包 exe 在小团体里分享**，
> 不上 Steam、不进任何商店渠道。本文档原为 Steam 上架计划，随定位变更整体重写。

## 1. 分发方式

- **形态**：单文件安装包或免安装 zip（解压即玩），Tauri 打包
- **渠道**：直接发给朋友（网盘 / 微信文件 / U 盘，怎么方便怎么来）
- **门槛**：双击就能玩，不需要联网、不需要注册任何东西

### Windows 的"拦路虎"要提前处理

| 问题 | 说明与对策 |
|---|---|
| SmartScreen 警告 | 没有代码签名证书的 exe，Windows 会弹"已保护你的电脑"。买证书对免费作品不划算——**在分享说明里写清楚点"仍要运行"的步骤**，配一张截图 |
| 杀毒软件误报 | 新 exe 无签名容易被误杀。打包后先用自己电脑 + 朋友电脑各测一遍；被误报就在说明里写加白名单方法 |
| 运行环境 | Tauri 依赖系统 WebView2，Win11 自带，Win10 老机器可能要装——打包时勾选"自动引导安装" |

## 2. 更新方式

- 版本号从 v0.1 开始老实打（`v主.次` 就够），exe 文件名里带版本：`花漾贴贴_v1.0.zip`
- 出新版本 = 重新发个包。小圈子规模，不做自动更新
- **存档和游戏本体分离**（存档放用户目录），覆盖安装/换版本不丢档；存档带 version 字段，老档自动升级
- 每个版本附一句话更新说明（"新增糖果系列 8 张贴纸"），就发在分享消息里

## 3. 素材授权记录（免费也要干净）

免费不等于没有版权责任，规矩不变：

| 事项 | 说明 |
|---|---|
| AI 出图 | 提示词不写具体 IP 名（美少女战士等）；游戏内"关于"页写明美术制作方式，坦荡 |
| 音效 | 自己录的没问题；素材库的逐条记录授权类型（CC0 / 署名），登记在 `assets/CREDITS.md` |
| BGM | 用素材库买断或 CC0，不用 AI 生成（省得多踩一个雷区）；来源同样登记 |
| 字体 | 游戏内用的字体要确认可免费商用/嵌入（思源系、站酷系都安全） |

## 4. 分享包里放什么

```
花漾贴贴_v1.0/
├─ 花漾贴贴.exe（或安装包）
├─ 开始之前看我.txt   ← SmartScreen 处理步骤 + 一句话介绍
└─ （游戏内自带"关于"页：制作说明、素材致谢）
```

## 5. 以后如果想走远一点（不承诺，只留路标）

- **itch.io**：免费游戏的天然货架，零成本零审核，挂上去就有个正经的"游戏主页"可以转发
- **Steam**：要交 100 美元押金且免费游戏拿不回来；除非哪天想要"有个 Steam 游戏"的仪式感，否则不值
- 无论走到哪一步，"免费、无商业化"不变——这是 01 文档 Scope 护栏里的第一条
