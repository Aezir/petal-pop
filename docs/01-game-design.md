# 01 游戏设计（GDD）

> GDD = Game Design Document，游戏设计文档。它回答"这个游戏到底是什么、玩家每分钟在干什么"。
> 本文档是活文档：开发中随时改，但改动要有理由。
> 2026-08 大改版：玩法从"手帐本"扩展为"贴法模板 × 主题画布"，游戏框架定为"一张书桌"。

## 1. 核心概念：一张书桌

**整个游戏就是一张俯视视角的书桌。** 没有菜单树，没有场景切换列表——桌上的每样东西就是界面本身：

| 桌上的东西 | 它是什么 |
|---|---|
| **存钱罐** | 点击进商店：明码标价买贴纸和本子 |
| **星星罐** | 点击进抽奖：便宜摇一次，随机出货 |
| **书立** | 收藏架：一排排手帐本和贴纸条，买到/摇到的都插在这里 |
| **桌面中心** | 贴贴台：从书立取下本子或贴纸，在这里正式开玩 |

两条铁律：

1. **玩家不扮演任何角色。** 游戏不预设"你是谁"，坐在桌前的就是玩家自己。怀旧感由物件和质感传达，不靠角色扮演。
2. **哪里都能贴。** 贴纸不要求必须贴进本子或画布——桌面、存钱罐、星星罐、书立，全是可贴表面。你的书桌会越来越像你自己的书桌。

## 2. 核心循环（Core Loop）

```
攒零花钱 → 存钱罐商店 / 星星罐 → 新贴纸、新本子插上书立
    ↑                                     ↓
    └── 完成主题任务、图鉴进度奖励 ← 取下来撕、贴、玩 ←┘
```

一圈时长目标：5~10 分钟。这是一个**免费情怀作品**：不考虑盈利，不为留存和时长做任何设计变形。想玩的人自会玩。

## 3. 贴法模板（设计语言）

主题不按"场景"想，按**贴上去以后发生什么**想——每个主题都是某种交互模板的实例，一个主题可以混两三种模板：

| 模板 | 一句话 | 例子 |
|---|---|---|
| 自由拼贴 | 想贴哪就贴哪 | 海报、手帐、杂志、明信片 |
| 穿戴搭配 | 往人身上搭 | 换装、美甲、化妆 |
| 叙事布景 | 布置一个小世界 | 房间、野餐、生日派对 |
| 容器填装 | 把东西塞进去 | 冰箱、行李箱、糖果罐 |
| 食物组装 | 贴纸就是食材 | 蛋糕、奶茶、便当 |
| 外观装饰 | 在物体表面贴 | 手机壳、水杯、痛包 |
| 手作组装 | 零件贴成成品 | 花束、串珠、雪花球 |
| 收纳整理 | 贴得整齐也是玩法 | 书架、衣柜、货架 |
| 动态贴纸 | 贴上去会动 | 水族箱、四季庭院、音乐盒 |

完整主题弹药库（100+ 个主题按模板归档）见 [07 主题库](07-theme-backlog.md)。

**首发实现前三个模板，各一个主题**：

| 首发主题 | 用的模板 | 验证什么 |
|---|---|---|
| **海报** | 自由拼贴 | 基础编辑器：图层、文字贴纸、自由排版 |
| **美少女换装** | 穿戴搭配 | 人体吸附辅助、成套搭配、造型卡 |
| **房间造景** | 叙事布景 | 空间前后遮挡、物件组合、生活痕迹 |

## 4. 统一贴贴台（编辑器架构）

**UI 不按主题各做一套**——底层是同一个编辑器，主题只往里加少量专属工具：

- **画布**：正在装饰的对象（海报纸 / 美少女底板 / 房间底板 / …桌面本身也是一张常驻画布）
- **贴纸盒**：当前可用素材，按人物、物件、装饰、文字分类
- **选中工具**：移动、旋转、删除、层级（2026-09 决定：不做缩放、翻转、自动成组，只留最质朴的真贴纸手感）
- **辅助规则**：吸附、裁切、镜像、区域限制（按主题开关）
- **主题工具**：文字贴纸、奶油笔、撒料器等（按主题追加）
- **完成展示**：拍照、滤镜、署名、收进作品集/导出图片

**核心原则：贴纸是统一的幻想，但不必是唯一的交互。** 玩家感觉自己一直在"贴贴"，底层操作可以是贴（拖放）、画（奶油、涂鸦）、撒（糖粉）、填（美甲底色）。首发只用到"贴"，架构上给另外三种留口。

## 5. 首发三主题细节

### 5.1 海报（自由拼贴）

- 底板：几款海报纸（纯色、渐变、复古印刷纹）
- 素材：装饰贴纸 + **文字贴纸**（标题字、日期、手写短句、印章、胶带、便利贴）
- 它是基础编辑器的试金石：图层、排版、文字做顺了，后面所有自由拼贴类主题（手帐、杂志、明信片）都是换皮

### 5.2 美少女换装（穿戴搭配）

- 角色底板贴纸 + 服装部件贴纸（发型/上装/下装/裙/鞋/饰品/手持物）
- **不做严格装备槽**：围巾可以贴到腰上、耳环可以当衣服装饰——自由是整个游戏的精神。提供吸附辅助（拖近对应部位时轻轻吸上去，"啪嗒"一声），但永远可以无视吸附随便贴
- 一套满意的搭配可存为"造型卡"，进图鉴展示

### 5.3 房间造景（叙事布景）

- 房间底板（首发 1~2 间：卧室起步）+ 家具、物件贴纸
- **生活痕迹贴纸是灵魂**：打开的书、没喝完的杯子、散落的袜子、趴着的猫——玩家贴的不是样板间，是一个有人住的故事
- 验证前后遮挡（z 序）和"贴在家具上的贴纸跟着家具走"的父子关系

## 6. 贴纸系统（撕取手感不变，仍是最高优先级）

**贴纸条（sheet）**：竖长一条，排着 6~10 张贴纸，顶端有挂孔。
- 每条属于一个主题系列；条上混角色/物件/装饰贴纸

**稀有度**：
| 等级 | 表现 | 出率参考 |
|---|---|---|
| 普通 | 哑光 | 70% |
| 闪卡 | 镭射反光（随鼠标流转） | 25% |
| 隐藏 | 每系列 1 张，图鉴上是剪影 | 5% |

**撕取手感（M0 唯一要攻克的东西）**：
- 按住边缘拖拽 → 沿模切线逐渐剥离 + 纸张弯曲形变
- 撕纸音效（多录几条随机播放）
- 撕下来带模切白边
- 不做撕坏惩罚：挫败感和治愈基调相反

## 7. 小卖部经济（存钱罐 + 星星罐）

- 货币只有一种：**零花钱**
- 获取：完成主题任务（主要）、图鉴里程碑、每日第一次打开游戏（"今天的零花钱"氛围感，不是留存钩子）

**花钱的两个渠道，同一个内容池，商品 = 贴纸条 + 本子**：

| 渠道 | 规则 | 情绪 |
|---|---|---|
| **存钱罐 → 商店** | 明码标价，想要哪个买哪个，但**很贵** | "非它不可"的确定性 |
| **星星罐 → 抽奖** | 约商店价 1/3，摇一次随机出贴纸条或本子 | 每天的怦然心跳 |

- 商店就是保底本身：运气再差，攒够钱总能直接买到缺的那件，不另设保底规则
- 经济数值开推演表（单任务收入 / 商店价 / 罐价 / 集齐期望摇数），不拍脑袋

## 8. 图鉴与收集

- 按主题系列展示：进度条、缺的显示剪影；本子也入图鉴
- 集齐一个系列 → 解锁纪念画布模板 + 零花钱奖励
- 图鉴是长线目标，创作是日常表达，两条线互相喂

## 9. 内容量规划（首发目标）

| 内容 | 数量 |
|---|---|
| 主题 | 3 个（海报 / 换装 / 房间） |
| 贴纸系列 | 每主题 2 个系列，共 6 条起 |
| 贴纸总量 | 约 100~140 张（换装部件占大头） |
| 角色底板 | 4~6 个 |
| 画布/本子 | 海报纸 3+、房间底板 1~2、手帐本 2+（星星罐可摇出） |
| 主题任务 | 15+ |
| 通关时长 | **不设指标**——收集节奏舒适就好 |

## 10. 情怀细节清单（Nostalgia checklist）

- [ ] 贴纸条顶端挂孔；撕痕、模切白边
- [ ] 镭射闪卡反光随鼠标流动
- [ ] 撕纸音效 + 按压"抹平"音效 + 拆塑封音
- [ ] 存钱罐投币/倒硬币声；星星罐玻璃珠碰撞声
- [ ] 书桌质感：木纹、台灯光晕、橡皮屑
- [ ] 圆珠笔涂鸦油墨感（偶尔断墨）
- [ ] 环境音：风扇声、远处放学铃
- [ ] 桌面上贴过的贴纸永久留在那（开机第一眼就是自己的历史）

## 11. 明确不做的（Scope 护栏）

- ❌ 任何商业化——游戏免费，商店和星星罐只花游戏内零花钱，永远
- ❌ 预设玩家角色、剧情线、对话系统（主题任务一句话描述就是全部叙事）
- ❌ 严格装备槽（吸附只是辅助，永远可以乱贴）
- ❌ 联网、账号、排行榜
- ❌ 为留存/时长服务的设计
- ❌ 撕坏惩罚机制
- ❌ 多语言首发（先中文）
- ❌ 手柄适配（鼠标就是"手指"）

## 12. 二期方向（首发不做，架构留口）

- **主题包持续上新**：按 [07 主题库](07-theme-backlog.md) 挑，优先花束（呼应游戏名）、冰箱、杂志——分别代表组装、填装、拼贴的深化
- **画/撒/填交互工具**：奶油笔、撒料器、颜色填充（食物、美甲主题的前置）
- **照片转贴纸**：导入照片 → 抠图 → 模切白边 → 专属贴纸。全程本地处理
- **动态贴纸**：会游的鱼、会长的植物、会亮的窗灯
- 其他平台适配、玩家自制贴纸包导入格式
