# 02 美术规划

美术是这个游戏的灵魂。路线：**AI 批量出图 + 手工挑选微调**。

## 1. 画风定义（先定死，再量产）

量产之前必须先做"画风锁定"：生成 20~30 张候选，挑出 3~5 张最对味的作为**风格锚点（style reference）**，之后所有出图都参照锚点，保证整批素材像一个画师画的。

参考方向（按怀旧优先级）：
- 90 年代~00 年代初国产贴纸的印刷感：饱和度偏高、描边粗、脸部比例夸张可爱
- 略带印刷偏色和网点感（太"干净"的现代 AI 风反而不像）
- 关键词方向：`90s Chinese sticker sheet, sailor uniform girl, bold outline, flat color, slight print offset`

## 2. 素材清单（Asset List）

### 贴纸类（核心，量最大；按首发三主题）
| 素材 | 数量估算 | 规格 |
|---|---|---|
| 换装：角色底板贴纸 | 4~6 | 512×512 PNG 透明底，含白边 |
| 换装：服装部件贴纸 | 40~50 | 自由贴放，吸附点大致对位即可（无严格装备槽） |
| 房间：家具与物件贴纸 | 30~40 | 含"生活痕迹"小件（摊开的书、趴着的猫） |
| 海报：装饰 + 文字贴纸 | 30~40 | 标题字、日期、手写句、印章、胶带、便利贴 |
| 隐藏闪卡 | 每系列 1 张 | 需额外做镭射遮罩图 |

### 场景与 UI 类
| 素材 | 说明 |
|---|---|
| **书桌俯视主场景** | 整个游戏的家：木纹桌面 + 存钱罐 + 星星罐 + 书立 + 台灯光晕；桌面/罐子/书立都是可贴表面 |
| 商店页 / 抽奖页 | 存钱罐、星星罐点开后的两个界面 |
| 画布底板 | 海报纸 3+ 款、房间底板 1~2 间、手帐本（封面 + 内页纸纹） |

| UI 全套 | 按钮、面板做成"文具"质感：橡皮、尺子、纸胶带 |

### 音频类（别漏了，情怀一半在声音里）
| 素材 | 来源建议 |
|---|---|
| 撕纸音效 ×5 | 自己录真贴纸（最真实、零成本） |
| 按压抹平、翻页、拆包装 | 自己录 |
| 存钱罐硬币声、星星罐玻璃珠声 | 自己录（真罐子 + 真硬币） |
| 环境音（风扇、远处放学铃） | 素材库（freesound 等，注意授权） |
| BGM 2~3 首 | 轻快 lo-fi / 八音盒风，素材库或 AI 生成 |

## 3. AI 出图流水线

每张素材走同一条流程，保证质量稳定：

```
1 生成：风格锚点 + 部位/角色描述 → 批量出 8~12 张
2 挑选：只留形体准确、风格一致的（淘汰率预期 70%+）
3 抠图：去背景转透明 PNG
4 修图：手工修边、统一描边粗细、加模切白边
5 入库：按命名规范存入 assets/，登记到素材清单表
```

**命名规范**（现在就定，后期救命）：
```
sticker_<系列>_<类型>_<编号>_<稀有度>.png
例：sticker_magic_char_01_shiny.png
    sticker_sailor_outfit-top_03_normal.png
```

## 4. 版权注意（AI 素材的坑）

- 出图时**不要**在提示词里写具体 IP 名（美少女战士、库洛魔法使等）——像不像是氛围问题，写名字是侵权证据
- 免费分发也一样要干净：游戏内"关于"页坦荡写明美术制作方式（AI 辅助 + 手工修）
- 手帐圈对 AI 美术敏感（评审提醒）：如果日后想公开传播，主视觉和角色底板考虑请画师重绘，AI 图退居草稿——小圈子分享阶段先不管这条
- 自己录的音效、买断授权的 BGM 留好来源记录，登记在 `assets/CREDITS.md`
