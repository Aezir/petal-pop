# 04 开发路线图

> 里程碑（milestone）思路：每一步都产出"能玩的东西"，用验收标准判断能不能进下一步。
> 时间按业余开发估算（每周 10~15 小时），全职可以砍半。

## M0 · 手感原型（3~4 周）

**只做一件事：撕贴纸爽不爽。** 用灰盒素材（丑方块也行），不碰美术。

做什么：
- 一条贴纸上撕下贴纸的完整交互（拖拽剥离、形变、音效）
- 撕下来能贴到一张空白页上（摆放、旋转）

**验收标准**：给 3 个朋友玩，不解释任何东西。如果有人撕了一张又主动撕第二张、第三张——手感成立，进 M1。如果没人想撕第二张，回炉重做手感，**不准进下一步**。

> 这是整个项目最重要的关卡。核心动作不好玩，后面做再多内容都是白费。

## M1 · 垂直切片（6~8 周）

> 垂直切片（vertical slice）= 游戏的一小块，但每一层都是成品质量：正式美术、正式音效、完整循环。业界用它验证"这游戏成不成立"。

做什么：
- **书桌俯视主场景**跑通：存钱罐点开是商店、星星罐点开是抽奖、书立取本子和贴纸条、桌面处处可贴
- 统一贴贴台（基础编辑器）：图层、移动/旋转、删除（不做缩放、翻转、自动成组）
- 第一个主题上线：**海报**（自由拼贴——基础编辑器的试金石）
- 完整核心循环：任务给零花钱 → 商店/星星罐 → 新贴纸条上书立 → 撕贴创作 → 交任务
- 第一个贴纸系列的正式美术（跑通 02-art.md 流水线）
- 存档读档（数据结构带 version 字段）
- **Tauri 打出第一个 exe**——分发全靠它，把打包风险提前踩掉（评审意见，采纳）
- 经济数值推演表：单任务收入 / 商店价 / 罐价 / 集齐期望摇数

**验收标准**：一个新玩家拿到 exe 双击就能玩，不看任何说明玩 20 分钟，并说得出"这游戏是干嘛的"。

## M2 · 内容量产 Alpha（8~10 周）

做什么：
- 第二、三个主题上线：**美少女换装**（吸附辅助、造型卡；顺带实测 AI 服装部件的可用率，太低就多用整套式造型贴纸）与**房间造景**（前后遮挡、生活痕迹贴纸）
- 素材流水线全速跑：补齐首发内容量（3 主题 6 系列、100+ 张贴纸、画布与本子）
- 图鉴系统、系列纪念画布
- 商店与星星罐的完整数值落地（按 M1 的推演表）
- 15+ 主题任务
- 作品导出图片功能

**验收标准**：从新档玩到全图鉴的完整流程无断点，内容量达到 01-game-design.md 的首发目标表。

## M3 · 打磨 Beta（4~6 周）

做什么：
- 情怀细节清单逐条实现（01 文档第 4 节）
- 性能：低配笔记本流畅（这游戏没理由卡）
- 小圈子 5~10 人先行测试，收集反馈修问题
- 做一页游戏介绍图文（随 exe 发给朋友用，也可发小红书随缘）

**验收标准**：测试的朋友里有人主动问"什么时候有新贴纸"；崩溃/丢档 bug 清零。

## M4 · v1.0 分发（1~2 周）

- 打正式包（zip 或安装包，见 05-release.md）
- 分享进小团体，收反馈
- 2 周内热修 bug，然后决定二期方向：照片转贴纸 / 新贴纸系列 / 平台适配

## 总览

| 里程碑 | 产出 | 累计时间 |
|---|---|---|
| M0 手感原型 | 撕贴纸 demo | ~1 个月 |
| M1 垂直切片 | 20 分钟完整体验的 exe | ~3 个月 |
| M2 内容 Alpha | 全内容可通关 | ~5.5 个月 |
| M3 打磨 Beta | 可分发质量 | ~7 个月 |
| M4 v1.0 分发 | exe 进小团体 | ~7.5 个月 |

> 以上是乐观值。新手首作的行业铁律是工期 ×2——**心理上按 12 个月准备**。好在免费作品没有发售日压力，慢就慢。

## 风险清单（提前认账）

| 风险 | 对策 |
|---|---|
| 撕取手感做不出"爽" | M0 卡死验收，最多回炉两次；实在不行降级为"点击撕取+好动画"，砍拖拽 |
| AI 出图风格不稳定 | 风格锚点先行；淘汰率高就接受，量大管饱 |
| AI 出服装部件可用率低 | 换装已改自由贴放（无严格装备槽），对位精度要求下降，但部件仍要"贴上去像回事"。M2 实测可用率，太低就多出整套式造型贴纸补位 |
| 主题清单诱惑扩散 | 07 主题库有 100+ 个主题，个个都想做。护栏：首发锁死 3 个，每期上新最多 1~2 个，新工具（画/撒/填）单独立项 |
| 业余时间断断续续 | 文档就是记忆，每次停工前把状态写进 docs/；里程碑内再拆周任务 |
| 没人玩 | 免费情怀作品，想玩的人自会玩；导出的手帐图带个小角标，随缘传播 |
